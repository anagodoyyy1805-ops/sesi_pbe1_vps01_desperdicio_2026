# Rastreamento de Consumo e Desperdício de Energia

## Descrição do Tema
Sistema backend desenvolvido para o SESI com o objetivo de registrar equipamentos e locais, monitorando o consumo energético mensal para identificar possíveis focos de desperdício e classificar o status do uso de energia.

## Tecnologias
* Node.js
* Express
* JavaScript
* Thunder Client
